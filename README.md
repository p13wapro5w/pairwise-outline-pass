# pairwise-outline-pass

角色贴近亮墙，外描边忽粗忽细，转身到背影又整圈消失：描边宽度按世界单位写死，相机缩放后屏幕宽度不一致；深度阈值只比绝对差，近裁剪和远裁剪处断线；法线阈值没归一化，斜面和曲面过渡处漏边；MSAA 下描边采样到边缘外，轮廓变虚；角色缩放后描边没跟着缩放，巨人像细线；遮挡关系只查深度，前景透明物体把描边截断；模板写入和描边 pass 顺序反了，重叠角色互相覆盖；多相机分屏共用一张描边图，左右屏串边；HDR 亮度阈值固定，暗部角色没有描边；动画形变时法线重建用上一帧，快速挥砍出现拖尾；分辨率切换后采样偏移没重算，描边偏向一侧；描边和后续色调映射顺序错，亮墙上的黑边被压没；远景角色描边和阴影贴图共用通道，互相覆盖。render/outline_pass.py 是核心，tests/test_outline_pass.py 15个红。要修的是：屏幕宽度；深度阈值；法线归一；MSAA 采样；缩放；透明遮挡；模板顺序；多相机隔离；亮度阈值；逐帧法线；分辨率偏移；色调映射顺序；通道隔离。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
